Política de privacidad

Cómo se manejan los datos cuando utilizas la aplicación PsicoRuta UV.

Responsable/desarrollador: Javier Felipe Contreras Díaz
Contacto de privacidad: nehreah@gmail.com
Fecha de vigencia: 9 de octubre de 2026

1. Acerca de PsicoRuta UV

PsicoRuta UV es una aplicación educativa independiente para consultar y organizar información de avance académico relacionada con un plan de estudios. No es una aplicación oficial de la Universidad del Valle ni está patrocinada, administrada o respaldada por esa institución. La información académica importante debe contrastarse con las fuentes oficiales.

2. Datos que maneja la aplicación

De acuerdo con las funciones incluidas en la versión revisada, la aplicación puede procesar:

  • Datos académicos que se muestran o editan en el perfil, como asignaturas, códigos de asignatura, calificaciones, créditos y estado de avance.
  • Texto extraído de un PDF que la persona selecciona para importar calificaciones; el procesamiento se realiza en el dispositivo.
  • Preferencias internas de la aplicación, por ejemplo si ya se mostró y aceptó el aviso inicial.
  • Información contenida en archivos JSON o PDF que la persona decide exportar.

La aplicación incluye archivos de datos de ejemplo dentro de su instalación para inicializar o mostrar perfiles de prueba. Estos archivos empaquetados no son datos enviados por usuarios a un servidor. No importes ni guardes información personal que no sea necesaria para la finalidad educativa.

3. Almacenamiento y procesamiento local

El perfil académico activo se guarda en el almacenamiento privado de la aplicación en el dispositivo. Las preferencias se guardan en las preferencias privadas de Android. Cuando se selecciona un PDF mediante el selector de documentos del sistema, la aplicación lee el documento para extraer información académica y procesarla localmente.

En el código revisado, el manifiesto de Android no declara el permiso INTERNET y las dependencias directas declaradas no incluyen SDKs de publicidad ni analítica. Por ello, la versión revisada no está configurada para enviar datos académicos a un servidor propio. Esta afirmación corresponde al código y manifiesto entregados; debe revisarse si en el futuro se incorporan permisos, SDKs, servicios o nuevas dependencias. La aplicación sí contiene enlaces a sitios externos y puede abrir otras aplicaciones del dispositivo, como se explica abajo.

4. Enlaces externos y aplicaciones de terceros

La aplicación contiene enlaces a recursos externos, incluidos sitios web y documentos relacionados con información académica, y puede iniciar una aplicación de correo mediante un enlace de correo electrónico. Cuando decides abrir uno de esos enlaces, el navegador, la aplicación de correo o el servicio externo seleccionado puede recibir información conforme a su propio funcionamiento y política de privacidad. PsicoRuta UV no controla las prácticas de privacidad de esos terceros.

La aplicación también permite abrir o compartir archivos generados. Si eliges una aplicación de terceros como destino para abrir o compartir un archivo, esa aplicación o servicio tratará el contenido de acuerdo con sus propias condiciones.

5. Exportación de archivos

La aplicación puede exportar el perfil académico como archivo JSON a la carpeta Descargas y generar informes PDF que también pueden guardarse en Descargas. Estos archivos pueden contener información académica. Una vez exportados, dejan de estar únicamente en el almacenamiento privado de PsicoRuta UV: otras aplicaciones con acceso al archivo o cualquier persona con quien lo compartas podrían acceder a su contenido. Revisa los archivos antes de compartirlos y guárdalos en un lugar seguro.

6. Copias de seguridad

En el código revisado, el manifiesto establece android:allowBackup="false" y las reglas de copia excluyen los dominios de almacenamiento privado, preferencias, bases de datos y almacenamiento externo para copias en la nube y transferencias entre dispositivos. La aplicación está, por tanto, configurada para excluir sus datos de las copias automáticas de Android. El comportamiento de transferencias entre dispositivos puede variar según la versión de Android y el fabricante; no debe considerarse una garantía absoluta en todos los dispositivos.

Para conservar el progreso, utiliza la función de exportación JSON si está disponible y guarda el archivo en un lugar seguro. Las copias exportadas a Descargas no se eliminan necesariamente al borrar los datos o desinstalar la aplicación, por lo que deben administrarse por separado.

7. Conservación y eliminación

Los datos del perfil y las preferencias permanecen en el almacenamiento de la aplicación mientras no se eliminen. Puedes borrar el perfil desde la función correspondiente de la app, borrar los datos de PsicoRuta UV desde los ajustes de Android o desinstalarla. La acción de eliminar el perfil hace que la aplicación pueda volver a cargar su plantilla inicial de datos. Los archivos JSON y PDF exportados a Descargas deben eliminarse por separado si ya no los necesitas. Si compartiste archivos con terceros, la aplicación no puede eliminarlos de los dispositivos o servicios de esos terceros.

8. Seguridad

La aplicación utiliza el almacenamiento privado de Android para el perfil activo y las funciones del sistema para seleccionar documentos. Los archivos que exportas a Descargas o compartes pueden quedar disponibles fuera del almacenamiento privado. Ningún método garantiza seguridad absoluta; protege tu dispositivo con bloqueo de pantalla, mantén el sistema actualizado y no compartas archivos con información que desees mantener privada. Esta política no afirma que la aplicación cifre los archivos exportados.

9. Público objetivo

PsicoRuta UV está concebida como una herramienta de organización académica. El responsable debe configurar de forma coherente el público objetivo y la clasificación de contenido en Google Play; el carácter educativo de la aplicación no implica por sí solo que esté dirigida a niños.

10. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones, permisos, bibliotecas o formas de tratamiento de datos. La fecha de vigencia indicada al inicio identifica la versión actual. Se recomienda consultar esta página después de actualizar la aplicación.
